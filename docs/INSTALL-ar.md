## الفكرة
تلفزيون LG بيقبل تطبيقات من برّه المتجر عن طريق **وضع المطوّر (Developer Mode)**. هتعمل حاجتين:
1. تفعّل وضع المطوّر على التلفزيون.
2. من الكمبيوتر (على نفس شبكة الواي فاي/الشبكة) تبعت ملف الـ `.ipk` للتلفزيون.

## الخطوة 1: على التلفزيون
1. اعمل حساب **مجاني** على موقع LG للمطورين: https://webostv.developer.lge.com (سجّل بإيميلك وفعّله).
2. من التلفزيون افتح **LG Content Store** وابحث عن **Developer Mode** ثم ثبّته.
3. افتح التطبيق وسجّل دخول بنفس الحساب.
4. فعّل **Dev Mode Status** (ON). التلفزيون هيعمل إعادة تشغيل.
5. افتح تطبيق Developer Mode تاني وفعّل **Key Server** (ON). هتشوف على الشاشة **عنوان IP** للتلفزيون و**Passphrase** (كلمة سر من 6 حروف تقريباً). سجّلهم.
6. في التطبيق فيه عدّاد وقت للجلسة. قبل ما يخلص افتح التطبيق واضغط **Extend** عشان التطبيق اللي ثبّتّه يفضل شغال.

## الخطوة 2: على الكمبيوتر (اختار طريقة واحدة)

### الطريقة أ: برنامج بواجهة رسومية (الأسهل)
نزّل **webOS Dev Manager** (برنامج مجاني مفتوح المصدر لويندوز وماك ولينكس):
https://github.com/webosbrew/dev-manager-desktop
1. افتحه واضغط **Add device** وحط **IP التلفزيون** و**Passphrase** (الـ port هو 9922 واسم المستخدم `prestodev`).
2. من تبويب **Apps** اختار **Install IPK** واختار الملف اللي نزّلته.
3. اضغط على التطبيق في القائمة ثم **Launch**.

### الطريقة ب: سطر الأوامر (لو عندك Node.js)
```sh
npm install -g @webos-tools/cli

# سجّل التلفزيون (غيّر 192.168.1.50 بعنوان IP بتاع تلفزيونك)
ares-setup-device --add tv -i "host=192.168.1.50" -i "port=9922" -i "username=prestodev" -i "default=true"

# هيطلب الـ Passphrase اللي ظهرت في تطبيق Developer Mode
ares-novacom --device tv --getkey

# ثبّت التطبيق وشغّله
ares-install --device tv com.iptvforall.app_0.1.0_all.ipk
ares-launch  --device tv com.iptvforall.app
```

## بعد التثبيت
التطبيق هيظهر باسم **IPTV For All** في قائمة تطبيقات التلفزيون (اضغط Home وابحث في آخر الصف).

أول مرة:
1. اضغط **Add playlist**.
2. اختار نوع القائمة: **M3U** (لينك قائمة) أو **Xtream** (سيرفر + اسم مستخدم + كلمة سر). الكتابة بتتم بالكيبورد اللي بيظهر على الشاشة، والأسهل ريموت **Magic Remote**.
3. افتح القائمة وشغّل قناة أو فيلم.

مفاتيح الريموت المهمة:
- **الأحمر**: مفضلة (وفي قائمة الأقسام: قفل/فتح قسم بالرقم السري).
- **الأخضر**: صوت وترجمة (داخل المشغّل) / رجوع لقوائم التشغيل (في القوائم).
- **الأصفر**: الإعدادات (في القوائم) / شكل الصورة (داخل المشغّل).
- **الأزرق**: تحديث القائمة (في القوائم) / الذهاب لوقت معيّن داخل الفيلم.
- **الأرقام** داخل الفيلم: اكتب الوقت واضغط OK (مثلاً `1 3 0` = دقيقة و30 ثانية). وتقدر تضغط على شريط التقدم بالماوس (Magic Remote) وتروح لأي مكان.

## لو حصلت مشكلة
- **الكمبيوتر مش شايف التلفزيون:** تأكد إنهم على نفس الشبكة، وإن Dev Mode و Key Server شغالين، وإن الـ IP صح.
- **التطبيق اختفى أو مش بيفتح:** الجلسة خلصت. افتح Developer Mode واضغط Extend ثم ثبّت تاني.
- **القائمة مش بتفتح وفيه رسالة CORS:** من **الإعدادات** حط "CORS proxy". ابعتلي الرسالة وأنا أساعدك.
- **فيلم بيقطّع:** من **الإعدادات** غيّر حجم "Smart cache" (64/128/256 MB) أو أقفله لو فيه مشكلة.
- أي حاجة تانية: ابعتلي موديل التلفزيون ونسخة webOS (Settings > General > About This TV) وصورة للمشكلة.

> ملاحظة: أنا جرّبت التطبيق بالكامل على المتصفح بسيرفر تجريبي، لكن لسه ماتجرّبش على تلفزيون حقيقي. أول تجربة على تلفزيونك مهمة، وأي مشكلة تظهر هصلحها.
