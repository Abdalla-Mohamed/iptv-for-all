# IPTV For All: شرح اللي اتعمل

مشغّل IPTV مفتوح المصدر لتلفزيونات **LG webOS**، شبه Smarter IPTV / IPTV Smarters. اتكتب من الصفر (مش مبني على تطبيق تاني)، بـ HTML + JavaScript عادي من غير build، وبيشتغل على webOS 4.0 فما فوق (تلفزيونات 2018 وما بعدها).

> **مهم:** التطبيق مفيهوش أي قنوات أو محتوى. المستخدم هو اللي بيضيف لينك قائمة تشغيل (M3U) أو بيانات اشتراكه (Xtream Codes).

> **حالة التجربة:** كل حاجة اتجرّبت على متصفح (Chromium) بسيرفر تجريبي بيحاكي مزوّد IPTV، وملف التثبيت `.ipk` اتبنى بنجاح بأداة LG الرسمية. **لسه ماتجرّبش على تلفزيون LG حقيقي.** أي سلوك خاص بالتلفزيون نفسه (المشغّل الداخلي، الكودكات، حدود الذاكرة) ممكن يظهر فيه اختلاف، وده أول حاجة لازم تتجرّب.

## 1. المميزات

### القوائم والمزوّدين
- **Xtream Codes** (السيرفر + اسم المستخدم + كلمة السر) مع التحقق من الحساب وقت الحفظ (بيرفض كلمة سر غلط ويقول إن الحساب منتهي).
- **M3U / M3U8** من لينك، مع دعم أسماء القنوات اللي فيها فواصل، وأقسام (group-title)، و`tvg-chno`.
- أكتر من قائمة تشغيل، وتعديل/حذف من الريموت.

### التصفح
- **بث مباشر / أفلام / مسلسلات** (مواسم وحلقات).
- أقسام، **بحث**، **مفضلة**، **شوهد مؤخراً**.
- **Continue watching**: تبويب الأفلام والمسلسلات بيفتح على اللي لسه ماخلصتوش مع شريط تقدّم، والحلقة بتفتح مسلسلها على نفس الحلقة.
- **صفحة تفاصيل الفيلم** (Xtream): القصة، الممثلين، المخرج، النوع، السنة، التقييم، وأزرار تشغيل / كمّل من هنا / ابدأ من الأول / مفضلة.
- قوائم ضخمة (عشرات الآلاف من القنوات) بدون تقطيع: بيتحط في الصفحة اللي ظاهر بس (VirtualGrid).

### المشغّل
- تغيير القنوات بـ CH+/CH-، وكتابة رقم القناة، وقائمة قنوات جانبية (OK).
- **التنقّل في الفيلم من أي مكان:** ضغط/سحب على شريط التقدم بـ Magic Remote (مع عرض الوقت)، أو كتابة الوقت بالأرقام (`1 3 0` = دقيقة و30 ثانية)، أو قفزات ±10 ثانية / ±1 دقيقة / ±10 دقايق.
- **استكمال المشاهدة** من آخر نقطة، وتشغيل الحلقة التالية تلقائياً.
- **صوت وترجمة**: قائمة لاختيار لغة الصوت والترجمة وحجمها، ولغات مفضّلة في الإعدادات (مثلاً صوت عربي + ترجمة إنجليزي) بتتطبّق تلقائياً.
- نسبة الصورة (Fit / Zoom / Stretch)، وإعادة محاولة تلقائية لو البث الحي وقع.

### الـ Smart Cache (الكاش الذكي) للأفلام
مشكلتها: مشغّل التلفزيون بيحمّل ثواني قليلة بس قدّام، فلو النت بطيء الفيلم بيقطّع ويرجع يحمّل. الحل في ملفات **MP4**:
- بيحمّل الملف على أجزاء صغيرة (HTTP range) حجمها بيتغير حسب سرعة النت، ويحتفظ بكاش في الذاكرة (64/128/256 ميجا) حوالين مكان المشاهدة.
- **بيستنى 8 ثواني** قبل ما يبدأ، ولو النت اتأخر عن الفيديو **بيوقف مرة واحدة ويملأ** بدل ما يقطّع كل شوية، وبيعرض "Caching 12 / 20 s · 450 KB/s". الضغط على OK بيتخطى الانتظار.
- لو وقّفت الفيلم الكاش بيكمّل تحميل.
- القفز لمكان بعيد بيحمّل من الـ offset الصح مباشرة (مش من أول الملف)، وبيدعم ملفات MP4 اللي الـ `moov` بتاعها في آخر الملف.
- لو حصل أي مشكلة (كودك غير مدعوم، السيرفر مش بيدعم range، الملف مش MP4 فعلاً، شبكة، مفيش تشغيل بعد 20 ثانية) **بيرجع للتشغيل العادي** عند نفس الموضع ويقولك ليه.
- **حدّه:** ملفات **MKV/AVI/TS مابتاخدش الكاش** (بتتشغّل بمشغّل التلفزيون)، لأن فك Matroska بـ JavaScript على التلفزيون تقيل. لو المزوّد عنده نفس الفيلم بصيغة `.mp4` هياخد الكاش.

### حفظ القوائم (سرعة وأوفلاين)
- القائمة المحمّلة بتتحفظ على التلفزيون (IndexedDB)، فالفتح التاني فوري وبدون أي طلب للنت.
- بتتحدّث في الخلفية (كل تشغيل / 6 ساعات / يوم / يدوي بالأزرق) وبتتبدّل في مكانها من غير ما تضيع مكانك.
- لو المزوّد واقع أو بطيء بيعرض النسخة المحفوظة مع تنبيه بدل رسالة خطأ.

### دليل البرامج (EPG)
- **Xtream:** الحالي والتالي من الـ API.
- **M3U:** ملف **XMLTV** (من `x-tvg-url` في القائمة أو لينك بتكتبه في خانة "Program guide URL")، عادي أو مضغوط `.gz`. بيتطابق بـ `tvg-id` وإلا باسم القناة. بيظهر "بيذاع دلوقتي" تحت كل قناة وفي لوحة المعلومات وفي المشغّل. بيتحمّل في الخلفية وبيتحفظ 12 ساعة.

### القفل العائلي (PIN)
- رقم سري من 4 أرقام. **الأحمر** على قسم في قائمة الأقسام بيقفله، والأقسام اللي اسمها XXX / Adult / 18+ بتتقفل لوحدها (تقدر تطفّي ده).
- المحتوى المقفول بيختفي من كل القوائم والبحث والمفضلة والعدّادات لحد ما تدخل الرقم (مفتوح 30 دقيقة أو لحد ما تخرج من القائمة).
- الرقم بيتحفظ مشفّر بسيط محلياً: ده بيبعد الأطفال، **مش حماية أمنية**.

### التحكم بالريموت
أزرار الألوان، أزرار الميديا، الأرقام، CH±، زر الترجمة، و Magic Remote بالضغط. ملخص الأزرار في `README.md`.

## 2. ازاي متقسّم (الكود)

حوالي **4000 سطر JavaScript** + 266 سطر CSS، من غير أي framework.

| الملف | وظيفته |
|---|---|
| `app/appinfo.json`, `index.html` | وصف التطبيق لـ webOS وتحميل السكربتات |
| `js/m3u.js` | قراءة M3U وتقسيمها لأقسام (بيشتغل في Node للاختبار كمان) |
| `js/xtream.js` | عميل Xtream API: فئات، قنوات، أفلام، مسلسلات، تفاصيل، EPG |
| `js/xmltv.js` | قراءة XMLTV: سريعة، مقسّمة على شرائح زمنية عشان الواجهة ماتهنجش، وبتحتفظ بنافذة حوالين "دلوقتي" بس |
| `js/provider.js`, `library-cache.js` | واجهة موحّدة للمزوّدين + حفظ القوائم في IndexedDB وسياسة التحديث |
| `js/cache-player.js` | الكاش الذكي: MP4 عبر MediaSource + mp4box.js |
| `js/engine.js` | غلاف الـ `<video>`: HLS أصلي أو hls.js أو الكاش الذكي، مسارات الصوت والترجمة، إعادة المحاولة |
| `js/widgets.js` | `VirtualGrid` (قوائم افتراضية)، أزرار وحقول، نافذة تأكيد وقفل PIN |
| `js/router.js`, `keys.js` | الشاشات وأزرار الريموت |
| `js/continue.js`, `langs.js`, `timeentry.js`, `parental.js` | منطق نقي (بدون واجهة) متغطّي باختبارات |
| `js/screens/*.js` | القوائم، النموذج، الإعدادات، التصفح، المسلسلات، تفاصيل الفيلم، المشغّل |
| `js/vendor/` | hls.js (Apache-2.0)، mp4box.js (BSD-3)، pako (MIT) |
| `tools/mock-server.mjs` | سيرفر تجريبي: Xtream + M3U + XMLTV + وسائط، مع تحكم في السرعة والأعطال للاختبار |
| `tests/` | اختبارات الوحدة والواجهة |

### قرارات تصميم مهمة
- **متوافق مع webOS 4 (Chromium 53):** الكود ES2015 بس. فيه حارس تلقائي (`npm run check:syntax`) بيفشل لو دخل كود بصياغة أو API أحدث من كده (مش بس في كودنا، في المكتبات كمان).
- **من غير build:** تفتح `app/index.html` بالمتصفح أو بتحزّمه `.ipk` مباشرة.
- **الصفحة ثابتة 1920×1080** وبتتصغّر تلقائياً على شاشة الكمبيوتر للتطوير.
- **المنطق مفصول عن الواجهة** عشان يتختبر في Node بسرعة.

## 3. الاختبار

- **63 اختبار وحدة** (`npm test`): M3U، Xtream، XMLTV، سياسة الكاش، لغات الصوت/الترجمة، إدخال الوقت، القفل العائلي، حفظ القوائم، "Continue watching".
- **7 مجموعات اختبار واجهة (e2e)** بـ Playwright/Chromium بتشغّل التطبيق فعلاً بأزرار الريموت والماوس بس (`npm run test:e2e`): الأساسيات والتشغيل، سيناريوهات الكاش، القوائم المحفوظة، Continue، الدليل، الصوت والترجمة، القفل العائلي.
- اختبار الكاش بيشمل: ميزانية ذاكرة صغيرة، قفز بعيد، قفز بعد نهاية الملف، ملف `moov` في الآخر، ملف مش MP4، نت بطيء، **وانقطاع فعلي في النص** (النت أبطأ من الفيديو، والتأكد إن الفيديو ماوقفش وإن الكاش وقف وملأ ورجع).
- **حارس التوافق** (`npm run check:syntax`) وبناء `.ipk` بأداة LG (`npm run package`).
- فيه ملف CI جاهز لـ GitHub Actions (`.github/workflows/ci.yml`) بيشغّل الحارس والاختبارات وبيبني الـ `.ipk` على كل push. ماراجعتش نتيجة تشغيله على GitHub من هنا، فبص على تبويب Actions في المستودع.

### مشاكل حقيقية الاختبارات لقتها واتصلّحت
- تغيير نوع القائمة (M3U ↔ Xtream) في نموذج الإضافة كان بيمسح اللي اتكتب قبله.
- القائمة الجديدة ماكانتش بتفتح بعد الحفظ.
- الكاش كان بيحمّل أكتر من ميزانية الذاكرة على نت سريع.
- بارامتر Range عشري كان بيتفسّر "نهاية الملف" غلط.
- ملف MP4 الـ `moov` بتاعه في الآخر كان بيقف التحميل بدري.
- ملف مش MP4 فعلاً كان بيعلّق بدل ما يرجع للتشغيل العادي.
- مفيش مؤشر "Caching" وقت الانقطاع النص-تشغيل.
- حذف أو تعديل قائمة كان هيرمي خطأ (دالة مش معرّفة).
- ترجمات HLS كانت بتفضل على عنصر الفيديو وتظهر في فيديوهات بعدها.
- قائمة الصوت والترجمة كانت بتبدأ على صف غلط.
- إزالة الـ PIN من الإعدادات كانت بتسيب القائمة القديمة المخفية على الشاشة.

## 5. اللي لسه ماتعملش

دليل قنوات بشاشة كاملة (جدول زمني)، XMLTV لحسابات Xtream، ملفات ترجمة خارجية، Catch-up، الكاش لملفات MKV، إضافة القوائم من الموبايل، Stalker portals، عرض أكتر من قناة (PiP)، وترجمة واجهة المستخدم/اتجاه RTL. وقابلية **التحويل لأندرويد** مشروحة في [`ANDROID-ar.md`](ANDROID-ar.md).

## 6. تشغيل للتطوير

```sh
npm install
npm run mock:media     # مرة واحدة، محتاج ffmpeg: بيولّد فيديو اختبار (مفيش محتوى حقيقي)
npm run dev            # http://localhost:8080  (Xtream: demo / demo، و M3U على /playlist.m3u)
npm test               # اختبارات الوحدة
npm run test:e2e       # اختبارات الواجهة
npm run package        # بناء ملف .ipk
```

مفاتيح لوحة المفاتيح بدل الريموت: الأسهم، Enter = OK، Esc = رجوع، F1–F4 = الأحمر/الأخضر/الأصفر/الأزرق، PageUp/PageDown = CH±.

## 7. التراخيص
المشروع Apache-2.0. المكتبات المرفقة: hls.js (Apache-2.0)، mp4box.js (BSD-3-Clause)، pako (MIT وzlib). تراخيصها في `app/js/vendor/`.
